# Logos

The Wazn mark and lockups, outlined SVG (no font dependency). Default: `wazn-logo-ar` on Arabic surfaces, `wazn-logo-en` on English ones. Inks: weights `#0A0A0A` (ink) or `#FBFAF7` (paper, reverse); beam and fulcrum `#B08A50` (brass) or `#C4A070` (brass on dark). Mono files use one ink only. Rules: README §3.
# Products

Product-family lockups for Wazn Screen, Purify, Engine and Agent: mark + "Wazn" (ink) + product word (brass) on one baseline, Arabic name beneath in muted ink (`#6E6B64`). For light grounds only; on dark, set the type in paper and the product word in `#C4A070`. Rules: README §9.
