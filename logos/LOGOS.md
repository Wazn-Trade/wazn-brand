# Logos

The Wazn mark and lockups, outlined SVG (no font dependency). Default: `wazn-logo-ar` on Arabic surfaces, `wazn-logo-en` on English ones. Inks: weights `#0E1B2C` (ink) or `#F6F3EC` (ivory, reverse); beam and fulcrum `#A9844C` (brass) or `#C9A46A` (brass on dark). Mono files use one ink only. Rules: README §3.
# Products

Product-family lockups for Wazn Screen, Purify, Engine and Agent: mark + "Wazn" (ink) + product word (brass) on one baseline, Arabic name beneath in muted ink (#55606E). For light grounds only; on dark, set the type in ivory and the product word in #C9A46A. Rules: README §9.
